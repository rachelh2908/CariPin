# CariPin: Pin what's happening

## Judges: start here
- Live app (no install, no login): https://teamcaripin27.pythonanywhere.com
- Back-end code (Flask + SQLite): app.py
- Front-end code (HTML, CSS, JavaScript, Leaflet): templates/index.html
- Design files, diagrams and screenshots: docs/

## What it does
CariPin lets people in Jamaica, Montserrat and Grenada report hazards
(flooding, landslides, erosion and more) on a shared map and see the
nearest police, fire stations and hospitals from any pin. It also contains
a safety card which can be used by and shared to emergency personnel. 

## Run it locally
1. Install Python 3: https://www.python.org/downloads/
2. Download this repository (Code > Download ZIP) and unzip it.
3. In a terminal inside the folder, run: pip install flask
4. Run: python app.py
5. Open http://127.0.0.1:5000 in a browser.
The database (pins.db) is created automatically on first run.
